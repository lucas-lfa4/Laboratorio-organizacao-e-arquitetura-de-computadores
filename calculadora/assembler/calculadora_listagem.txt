CALCULADORA INTERATIVA -- RV32I na DE2-115
==============================================================================

O programa fica em laco: le as chaves, executa a operacao escolhida e mostra o
resultado nos LEDs vermelhos. Mude as chaves e o resultado muda na hora.

CHAVES
  SW[17:14]  operacao (0 a 15, tabela abaixo)   -> o numero aparece em LEDG[3:0]
  SW[13:7]   operando A, 7 bits COM SINAL (-64 a +63)
              SW13 e o bit de sinal: SW13=1 => A negativo (complemento de 2)
  SW[6:0]    operando B, 7 bits sem sinal (0 a 127)

BOTOES
  KEY[0]     reset
  KEY[3]     solto   : LEDR[17:0] = resultado[17:0]
             apertado: LEDR[13:0] = resultado[31:18]  (parte de cima)

OPERACOES (SW[17:14])
   0 0000  ADD    A + B            8 1000  SLT    A < B (com sinal)
   1 0001  SUB    A - B            9 1001  SLTU   A < B (sem sinal)
   2 0010  AND    A & B           10 1010  ADDI   A + 5
   3 0011  OR     A | B           11 1011  XORI   A ^ -1  (= NOT A)
   4 0100  XOR    A ^ B           12 1100  SLLI   A << 4
   5 0101  SLL    A << B[4:0]     13 1101  SRLI   A >> 4  (logico, entra 0)
   6 0110  SRL    A >> B[4:0]     14 1110  SRAI   A >> 4  (aritmetico, entra o sinal)
   7 0111  SRA    A >> B[4:0]     15 1111  SLTIU  A < 5   (sem sinal)

EXEMPLOS PARA A APRESENTACAO  (LEDR17 ... LEDR0; 1 = aceso)
  ADD 5 + 3:   SW = 0000 0000101 0000011
               LEDR = 00 0000 0000 0000 1000  (8)
  SRA x SRL com A negativo: A = -16 (SW[13:7] = 1110000), B = 2
    SRA (0111): LEDR = 11 1111 1111 1111 1100  (-4: entram 1s pela esquerda)
    SRL (0110): LEDR = 11 1111 1111 1111 1100  e com KEY[3] apertado:
                LEDR[13:0] = 00 1111 1111 1111  (entraram 0s em cima: 0x3FFFFFFC)
                (no SRA, com KEY[3] apertado: LEDR[13:0] = 11 1111 1111 1111)
  SLT x SLTU com A = -1 (SW[13:7] = 1111111), B = 1
    SLT  (1000): LEDR0 = 1   (-1 < 1 com sinal)
    SLTU (1001): LEDR0 = 0   (0xFFFFFFFF < 1 sem sinal? nao)
  NOT: XORI (1011) com A = 0 => LEDR todos acesos (resultado 0xFFFFFFFF)

Obs.: SLL/SRL/SRA usam so B[4:0] (0 a 31), como manda o RISC-V.

PROGRAMA (assembler/calculadora.asm)
==============================================================================

0x000     40000A13          addi x20,x0,1024      x20 = 0x400 (base do MMIO)
0x004     01900513          addi x10,x0,25        x10 = 25 (usado para estender o sinal de A)
0x008     000A2083  LOOP    lw x1,0(x20)          x1 = chaves SW[17:0]
0x00C     00E0D293          srli x5,x1,14         op = SW[17:14]
0x010     00F2F293          andi x5,x5,15         
0x014     01209113          slli x2,x1,18         A = SW[13:7] com sinal: sobe o bit 13 para o bit 31...
0x018     40A15133          sra x2,x2,x10         ...e desce 25 bits estendendo o sinal (-64..63)
0x01C     07F0F193          andi x3,x1,127        B = SW[6:0] (0..127)
0x020     005A2623          sw x5,12(x20)         LEDG = numero da operacao
0x024     00329313          slli x6,x5,3          deslocamento na tabela = op * 8 (2 instrucoes por caso)
0x028     00000397  BASE    auipc x7,0            x7 = endereco desta instrucao
0x02C     006383B3          add x7,x7,x6          
0x030     00C38067          jalr x0,x7,12         salta para TABELA + op*8  (TABELA = BASE + 12)
0x034     00310233  T0      add x4,x2,x3          op 0  ADD   A + B
0x038     07C0006F          jal x0,124            
0x03C     40310233          sub x4,x2,x3          op 1  SUB   A - B
0x040     0740006F          jal x0,116            
0x044     00317233          and x4,x2,x3          op 2  AND   A & B
0x048     06C0006F          jal x0,108            
0x04C     00316233          or x4,x2,x3           op 3  OR    A | B
0x050     0640006F          jal x0,100            
0x054     00314233          xor x4,x2,x3          op 4  XOR   A ^ B
0x058     05C0006F          jal x0,92             
0x05C     00311233          sll x4,x2,x3          op 5  SLL   A << B[4:0]
0x060     0540006F          jal x0,84             
0x064     00315233          srl x4,x2,x3          op 6  SRL   A >> B[4:0] logico
0x068     04C0006F          jal x0,76             
0x06C     40315233          sra x4,x2,x3          op 7  SRA   A >> B[4:0] aritmetico
0x070     0440006F          jal x0,68             
0x074     00312233          slt x4,x2,x3          op 8  SLT   A < B com sinal
0x078     03C0006F          jal x0,60             
0x07C     00313233          sltu x4,x2,x3         op 9  SLTU  A < B sem sinal
0x080     0340006F          jal x0,52             
0x084     00510213          addi x4,x2,5          op 10 ADDI  A + 5
0x088     02C0006F          jal x0,44             
0x08C     FFF14213          xori x4,x2,-1         op 11 XORI  A ^ -1 (= NOT A)
0x090     0240006F          jal x0,36             
0x094     00411213          slli x4,x2,4          op 12 SLLI  A << 4
0x098     01C0006F          jal x0,28             
0x09C     00415213          srli x4,x2,4          op 13 SRLI  A >> 4 logico
0x0A0     0140006F          jal x0,20             
0x0A4     40415213          srai x4,x2,4          op 14 SRAI  A >> 4 aritmetico
0x0A8     00C0006F          jal x0,12             
0x0AC     00513213          sltiu x4,x2,5         op 15 SLTIU A < 5 sem sinal
0x0B0     0040006F          jal x0,4              
0x0B4     004A2403  OUT     lw x8,4(x20)          x8 = botoes KEY[3:0] (apertado = 0)
0x0B8     00847413          andi x8,x8,8          isola KEY[3]
0x0BC     00040663          beq x8,x0,12          KEY[3] apertado? -> mostra parte de cima
0x0C0     004A2423          sw x4,8(x20)          LEDR = resultado[17:0]
0x0C4     F45FF06F          jal x0,-188           volta a ler as chaves
0x0C8     01225493  ALTO    srli x9,x4,18         resultado[31:18]
0x0CC     009A2423          sw x9,8(x20)          LEDR = resultado[31:18]
0x0D0     F39FF06F          jal x0,-200           volta a ler as chaves

Como o laco funciona:
 1. le SW em 0x400 e separa op, A e B (shifts e mascaras);
 2. salta para TABELA + op*8 com auipc + add + jalr (cada caso: operacao + jal OUT);
 3. em OUT le KEY em 0x404; se KEY[3] apertado mostra resultado[31:18], senao [17:0];
 4. escreve em LEDR (0x408) e volta ao passo 1.
