CALCULADORA INTERATIVA v2 -- as 37 instrucoes do RV32I na DE2-115
======================================================================================

Legenda das chaves:  + = para cima (1)   - = para baixo (0)

CONTROLES
  SW17..SW14  escolhem a operacao dentro do grupo (0 a 15)
  KEY1 segurado  -> grupo 2 (operacoes 16..31)   KEY2 segurado -> grupo 3 (32..47)
  nenhum dos dois -> grupo 1 (0..15)             (se os dois: vale o KEY2)
  SW13..SW7   operando A, com sinal (-64..63; SW13 + = negativo)
  SW6..SW0    operando B, 0..127
  LEDR17..0   resultado (bits 17..0)
  KEY3 segurado -> LEDR13..0 mostram os bits 31..18 do resultado
  LEDG5..0    numero da operacao (0..47): LEDG4 aceso = grupo 2, LEDG5 aceso = grupo 3
  KEY0        reset

Detalhes:
  * Loads (LB, LH, LW, LBU, LHU) leem a palavra fixa 0x8765F0A1 (bytes A1 F0 65 87).
    B[1:0] = SW1 SW0 escolhe o byte (0..3); nos de meia-palavra so o SW1 conta (0 ou 2).
  * Stores (SB, SH) partem de 0x11223344 e trocam so o byte/metade escolhido por A;
    o resultado mostrado e a palavra lida de volta com LW.
  * Branches mostram 1 se o desvio seria TOMADO e 0 se nao.
  * LUI, AUIPC, JAL e JALR nao dependem das chaves: mostram valores fixos:
      LUI = 0x12345000   AUIPC = 0x000011B4   JAL = 0x00000248   JALR = 0x0000025C
    (AUIPC = endereco da instrucao + 0x1000; JAL/JALR = endereco de retorno PC+4.
     Se o salto falhasse, o resultado seria 0.)

EXEMPLOS (LEDR17 ... LEDR0)
  ADD 5 + 3 (grupo 1, op 0):  SW = - - - - | - - - - + - + | - - - - - + +
     LEDR = 00 0000 0000 0000 1000  (8)
  LB x LBU, byte 0 = 0xA1 (grupo 2, op 21 / op 24), B = 0:
     LB : LEDR = 11 1111 1111 1010 0001   (0xFFFFFFA1, sinal estendido)
     LBU: LEDR = 00 0000 0000 1010 0001   (0x000000A1)
  BLT x BLTU com A = -1, B = 1 (grupo 3, op 34 / op 36):
     BLT : LEDR0 aceso (tomado: -1 < 1)    BLTU: LEDR0 apagado (0xFFFFFFFF < 1? nao)
  SB com A = 5 e B = 2 (grupo 2, op 26): 0x11223344 -> 0x11053344
     LEDR = 01 0011 0011 0100 0100 ;  com KEY3: LEDR13..0 = 00 0100 0100 0001 (0x0441)
